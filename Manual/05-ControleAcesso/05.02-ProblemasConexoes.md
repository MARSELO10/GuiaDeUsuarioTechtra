# 🔴 Como resolver problemas de conexão

## Primeiro passo:

Para que o Acesso Techtra se comunique com um dispositivo, é necessário que o mesmo esteja acessível na rede. Para averiguar isso, acesse o servidor onde o Acesso Techtra está instalado, tecle Windows + R, digite "CMD" sem as aspas e aperte Enter.

Na tela que abrir, digite o comando "ping" seguido pelo ip do dispositivo que está tentando conectar. Exemplo: ping 192.168.1.201. Conforme exemplificado na imagem abaixo: 

<img width="727" height="289" alt="image" src="https://github.com/user-attachments/assets/b4621c4d-b493-428a-8004-dcbdcd4de87e" />

O resultado esperado são 4 pacotes enviados e 4 pacotes recebido, conforme mostrado na imagem acima. Caso, não obtenha sucesso no ping, verifique as seguintes coisas:

(1) O dispositivo está com o cabo de rede ligado?

(2) O servidor está ligado na rede?

(3) O servidor está na mesma faixa de IP do dispositivo? 

---

## Segundo passo:

Obtendo sucesso no passo anterior, verifique se o login e ou senha utilizados para cadastrar o dispositivo no Acesso Techtra estão corretos. A maioria dos dispositivos possui interface web, uma boa forma de verificar o login e senha é acessando a interface web, pois estes valores de login e senha são os mesmos usados para cadastrar o dispositivo no Acesso Techtra.

Para acessar a interface web, abra o navegador de internet, digite o IP do dispositivo e aperte enter, deve ser carregada um tela de login similar a da imagem abaixo: 

<img width="1003" height="564" alt="image" src="https://github.com/user-attachments/assets/13672eeb-30b8-4f01-93a3-562731b5a3ba" />

Caso consiga realizar o login com sucesso, usando usuário e senha, isso significa que os valores digitados para cadastrar o dispositivo no Acesso Techtra estão corretos. Alguns dispositivos não possuem interface web, nestes casos, acesso o manual do equipamento no site da Intelbras e veja como realizar o reset do dispositivo para o padrão de fabrica, dessa forma o login e senha podem ser redefinidos. 

---

## Terceiro passo:

Verifique com o administrador da rede se o Acesso Techtra tem liberações de firewall e as portas de rede a seguir estão liberadas: 4442, 4441, 4440, 4443, 4444, 4445, 5003, 5004, 5832, 50007, 50008, 50009, 4370, 37777, 80, 8080, 5677, 12356.
