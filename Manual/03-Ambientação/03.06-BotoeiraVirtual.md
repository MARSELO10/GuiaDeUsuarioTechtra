# 🔓Botoeira Virtual

---

Com o objetivo de facilitar a usabilidade e operação do sistema é exibido uma botoeira virtual, permitindo que o operador realize a abertura do ponto de acesso remotamente.

O Recurso é localizado na barra de menu da tela:

<img width="213" height="397" alt="image" src="https://github.com/user-attachments/assets/6ad2a727-4eb9-48a7-a3aa-67577562b72a" />

Selecionando a controladora para o sentido que deseja, você pode colocar uma observação do motivo da liberação manual e clicar no botão liberar passagem

<img width="352" height="331" alt="image" src="https://github.com/user-attachments/assets/767f1dca-204a-4a72-a0d3-a379b0d28be2" />

Importante: O botão virtual aparece para todos os operadores que tem permissão na tela de pontos de acesso, desde que a função esteja habilitada pelo Administrador na tela de Configurações > Admin > Permissão de Usuário > Realizar Liberação Manual - Caixa estar marcada
