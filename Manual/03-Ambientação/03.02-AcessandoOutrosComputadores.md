# 🧑‍💻👨‍💻 Acessando de outros computadores

---

O Techtra Acessos é um sistema centralizado, ou seja, é necessário instalar ele apenas no servidor. Para usar o Techtra Acessos em outras máquinas, basta digitar https:// + endereço IP do servidor + 5443.

Exemplo:

Digitando https:// 172.25.3.202:5443, sendo 172.25.3.202 o IP do servidor e 5443 a porta de comunicação, o navegador será redirecionado para a tela da imagem abaixo. Note que no primeiro acesso o navegador vai perguntar se pode confiar no sistema sendo acessado.
