# 🛥️Orientações de Uso em Navegadores

---

Atualmente o software Techtra Acessos opera no ambiente Web sendo utilizado por meio de navegadores. Em alguns casos pode ser necessário configurações adicionais nos navegadores para o funcionamento correto do sistema e correções de eventuais problemas. O navegador suportado atualmente é o Chrome®.

---

### Limpeza de dados em cache

O termo cache é determina as informações salvas que refletem componentes estáticos do site, como por exemplo uma imagens e textos que constituem a página. Sendo um artificio utilizado pelos navegadores para que toda vez que uma página seja aberta o navegador não requisitar todos os dados novamente do servidor.

A utilização do cache em alguns momentos pode implicar na exibição não correta dos dados que estão no servidor, pois estes estão sendo obtidos por meio do armazenamento do navegador. Neste caso recomendamos realizar o seguinte procedimento:

» Atalho Chrome®: CTRL + SHIFT + R

Por meio deste comando será realizado a limpeza dos dados em cache dos navegadores corrigindo a exibição de dados que possam estar sendo apresentados de forma incorreta ou não sendo apresentados.
