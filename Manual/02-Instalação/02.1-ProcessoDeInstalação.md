# 🛜 Instalação

A instalação da solução no servidor deve ser feita exclusivamente em Sistema Operacional Windows nas suas versões Windows® 10 64bits, Windows 11 64bits, Windows® Server 2019 Standard 64bits (Desktop Experience).

---

## Processo de instalação

Após efetuar o download do instalador do software, clicar sobre o arquivo do instalador para Executar como Administrador.

Uma nova janela se abrirá e será necessário clicar no botão Próximo a medida em que for pedido, para que o processo seja executado.

<img width="497" height="385" alt="image" src="https://github.com/user-attachments/assets/4f2413aa-0f18-4c34-bd08-3ec9bd1ae1e2" />

Após o término da instalação, ele irá iniciar o sistema no seu navegador Google Chrome

## Mensagem de Site não seguro

Quando ocorre o primeiro acesso do computador será apresentado o seguinte aviso:

<img width="698" height="394" alt="image" src="https://github.com/user-attachments/assets/37c460fc-3731-4305-9547-fed7f4c176de" />

Isto ocorre pois o computador ou navegador que está tentando o acesso ao servidor Techtra Acesso não conhece o certificado HTTPS do Techtra como seguro

Neste caso o aviso poderá ser ignorado selecionando a opção Avançado e após Ir Para "Localhost" (Não Seguro).

<img width="721" height="558" alt="image" src="https://github.com/user-attachments/assets/946b8521-e48a-4788-ae41-1b523a52696a" />

A mensagem de "Não Seguro" poderá persistir durante a utilização porem não será necessário nenhuma ação, este aviso apenas ocorre devido ao navegador ou sistema não conhecer as credenciais HTTPS
